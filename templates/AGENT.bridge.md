# Azurance API agent bridge

When the canonical Azurance agent skill is installed, read `.agents/skills/azurance-api/SKILL.md` before implementing or reviewing Azurance API integrations. It points to the exact provider/insurer references and OpenAPI contracts. If the project uses another skill directory, use the equivalent installed `azurance-api/SKILL.md` there; otherwise use `.azurance/llm/context.md` and its provider/insurer references.
